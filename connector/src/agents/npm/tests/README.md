These Windows shim fixtures were generated by the package managers' shim writers with an entry at
`@openai/codex/bin/codex.js` (Node shebang). Line endings are normalized to LF so they are readable on every host.

- `npm.cmd`: `cmd-shim` 9.0.2, global prefix → `node_modules/@openai/codex/bin/codex.js`.
- `pnpm.cmd`: `@zkochan/cmd-shim` 9.0.8 (pnpm's shim writer), `createCmdFile: true`, local `.bin` → sibling package, including its generated `NODE_PATH` block.
- `yarn.cmd`: `@zkochan/cmd-shim` 3.1.0 (yarn classic 1.22.22's declared shim writer), global bin → `../Data/global/node_modules/...`.

The tests create the corresponding package trees dynamically, including pnpm's symlinked store. No package manager
or Node process is needed to run the Rust tests. Bun's executable shims are left unchanged; Windows Bun runtime
behavior has not been verified here.

The fixtures use the production harness declarations and real native paths. The shared tests live in `tests.rs` so
the repository's architecture check can still forbid harness names in production agents code.
